## Choices and notes

- Missing inputs: width_m, dwidth_00_14 and pre_p75 NaN are imputed by the training-fold median inside the logistic pipeline (gradient boosting uses NaN natively). Chosen before any AUC. pre_p75 is NaN for 104 of 352 units (67 of 112 Hậu main units: no 2012 composite and the 2013 Hậu composite covers ~26% of points, so the 2012-14 mean has < 2 valid years). This is a property of the frozen pre_p75 definition.
- Event-only filter: (unit_type in {vụ, điểm} or source_type == decision_via_news) and source_type != official_list_via_news: 43 of 124 rows (drops the 69 warned-reach list rows incl. 5 hamlet-level "điểm" rows from those lists, 5 ODM 2018 reaches, 6 news "đoạn" rows and 1 "khu vực" row).
- Commune-bank units = (channel, side, province, district, commune) (province only disambiguates; same 182 groups without it). A unit is reported-positive if it holds a bank point matched to a row by inventory_build (row units x row communes). Satellite labels and covariates by the same functions as the 2 km units.
- Blocks: main channels mean chainage of the unit points / 1000, island channels (tiles.json chainage_m - border_m[parent]) / 1000, block = river_int(km // 10) (same rule as H1/H2).
- One training fold = all blocks but one; every block is tested once. Reported labels of commune-level rows cover whole communes (D4 note), so reported positives are spatially contiguous.
