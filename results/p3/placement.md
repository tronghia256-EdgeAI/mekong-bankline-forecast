# R2: placement error of reported rows

Generated by `python src/p3_placement.py` (306 s, 4 worker processes). Design and criterion fixed before running in `docs/p3_plan.md` R2 (protocol deviation 6). This is a robustness check of the confirmatory H3 (`results/p2/h3.md`) and of the exploratory omission / commission shares (`results/p2/explore_reporting.md`); it changes neither.

## Design

- The 124 usable inventory rows carry no coordinates; each labels a list of 2 km units (`units_2km`). For k = 1 and 2 every unit of a row moves k units (2-4 km) along its bank, in one random direction per row, on its own channel and side (unit id channel_side_index; consecutive index = adjacent 2 km), clipped at the lowest / highest in-scope index of that channel-side. 200 draws per k, seed 0; one direction matrix serves both k (draw j of k = 2 moves each row twice as far as draw j of k = 1).
- Reported labels rebuilt with `h3.reported` on the shifted rows (any row = `rep`; event rows only = `rep_event`, the H3 event-only sensitivity). Satellite label (`lab_p75_20`), features, 10 km blocks and leave-one-block-out folds unchanged (`h3.unit_table`, 343 units, 27 blocks), so the satellite-trained scores are fixed and only the reported-trained model is refitted.
- Per draw: logistic AUC matrix and ΔAUC = AUC(reported) - AUC(satellite) (point values); omission = share of the 43 satellite-eroding units with no reported (no event) row; commission = share of reported units with win_p75 < 9.3 m (`explore_reporting.FLOOR`).
- First 20 draws per k: the full H3 decision (`h3.analyse`, B = 1000 block bootstrap, `h3.verdict`; logistic model, built_1km terciles, as the primary analysis), for the any-row label (the H3 decision) and the event-only label (its sensitivity row).
- k = 0 is the original inventory; the script asserts that it reproduces `data/processed/h3_metrics.csv` and the counts of `results/p2/explore_reporting.md` (omission 12/43, no event row 25/43, commission 201/260).

## Reading

- The verdict holds, but the reported-trained point values are placement-sensitive. Trained on reported (any row): AUC against satellite 0.57 (original) -> 0.56 (k = 1) -> 0.50 (k = 2), AUC against reported 0.50 -> 0.58 -> 0.58, so ΔAUC -0.08 -> +0.01 -> +0.08. The original AUC against reported is lower than in 100% (k = 1) and 97% (k = 2) of the displaced draws, and the weak satellite signal of the reported-trained model fades as rows move: the original placement carries a little real erosion information that a 2-4 km shift removes, while displaced labels are, if anything, more learnable from the physical covariates. (Diagnostic, not part of the design: dropping instead of clipping units beyond a channel end gives the same pattern in 40 draws, so clipping does not cause it.)
- Trained on satellite, ΔAUC stays negative (-0.21, -0.24) and its block-bootstrap CI excludes 0 in 20 of 40 full-decision draws (any row; original: no). H3 still fails in every draw because the exposure-tercile conditions fail: terciles monotone in 18 / 11 and T3 - T1 CI excluding 0 in 0 / 0 of 40 draws (trained on reported / satellite).
- Event rows: ΔAUC trained on reported -0.05 -> +0.04 -> +0.12; its CI excludes 0 (positive) in 6 of 20 k = 2 draws; tercile conditions met in 22 (monotone) / 0 (trend) of 40 draws, so the event-only sensitivity is not supported in any draw either.
- Omission and commission medians barely move (omission 26% / 28%, commission 77% / 77% at k = 1 / 2), because reported rows cover 76% of units and a shift mostly moves labels between reported units.

## Caveats

- 58 of the 124 rows list units on more than one channel-side (a commune that holds a main bank and island banks); every unit moves on its own channel-side, all in the row's direction. Direction on island rings follows the ring index, which is not up/downstream; islands are clipped at the ring index ends although a ring is closed.
- Shifted units that land in an index gap (no in-scope unit there: dropped ring banks of deviation 5, or out of scope) label nothing: mean share of shifted unit slots in a gap 3.5% (k = 1), 5.0% (k = 2). Clipping at channel ends and overlaps inside a row merge units: on average 19.5 (k = 1) and 39.3 (k = 2) of the 685 row-unit entries disappear per draw. Both make shifted labels slightly sparser than the original.
- Rows overlap heavily (warned-reach lists and commune rows cover whole communes, 76% of units reported), so a shift of 2-4 km changes only part of the unit labels (column "labels changed": about 49 of 343 at k = 1, 76 at k = 2); the check measures sensitivity to placement, not to coverage.
- Full-decision draws are 20 per k (run time); point values cover all 200. Block-bootstrap intervals are for fixed scores (as in H3).
